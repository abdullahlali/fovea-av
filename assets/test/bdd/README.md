# Test images

| File | Use |
|------|-----|
| `street.jpg` | **Default** — forward-facing street scene (bus + pedestrians). Use this for demos. |
| `dashcam_interior.jpg` | **Bad example** — driver POV from inside the car. YOLO will misbehave; Fovea expects **road-facing** camera input. |

Fovea is built for **forward dashcam / street camera** views — what an autonomous vehicle sees ahead, not the cabin interior.

Download more from [BDD100K](https://www.bdd100k.com/) or [KITTI](https://www.cvlibs.net/datasets/kitti/).
