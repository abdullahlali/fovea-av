# Dashcam sample clips

| File | Description |
|------|-------------|
| `street.mp4` | **Default video demo** — forward-facing dashcam clip (trimmed ~15s). Generated by `scripts/download_sample_video.py`. |

Fovea expects **road-facing** camera input — the same POV as `assets/test/bdd/street.jpg`.

## Generate assets

```bash
pip install kagglehub
python3 scripts/download_sample_video.py
```

The script uses the cached [BDD100K Kaggle dataset](https://www.kaggle.com/datasets/solesensei/solesensei_bdd100k) to sync the canonical street still image (`b1c66a42-6f7d68ca.jpg`, city street scene).

BDD Kaggle is **image-only** (10th-second keyframes). For video replay, the script trims a forward dashcam clip unless you pass your own BDD video:

```bash
FOVEA_BDD_VIDEO=/path/to/bdd/video.mp4 python3 scripts/download_sample_video.py --force
```

## Run

```bash
./build/app/fovea_app assets/test/dashcam/street.mp4
./build/app/fovea_app assets/test/dashcam/street.mp4 --panel
```
